HOW TO HUMANIZE (QuillBot Premium) - markerless method
======================================================
For each NN = 01..24:
1. Open part_NN.txt -> Ctrl+A -> Ctrl+C.
2. Paste into QuillBot -> Humanizer -> Humanize.
3. Copy the result and paste it into part_NN_done.txt.

THE ONE RULE: keep the SAME NUMBER OF PARAGRAPHS in the SAME ORDER, each
separated by a BLANK LINE. Do not merge two paragraphs into one or split one
into two. (Each part lists how many paragraphs it must have - see counts below.)

No @@markers this time (QuillBot deletes them). I map your paragraphs back by
order, and I verify the count matches before writing them into the .docx.
If a part's count doesn't match, I'll tell you which one to re-check.

Humanize prose only - tables/numbers/specs were never included in these files.

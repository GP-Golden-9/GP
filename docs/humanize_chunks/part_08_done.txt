To supervise robot operations, effective dashboard and monitoring systems are required, particularly in search and rescue scenarios where real-time situational awareness is critical. The literature indicates that operators need to be able to see robot status, sensor data and perception outputs clearly and responsively to enable informed decision-making during missions.

Web-based dashboards are often used in robotic systems because of their cross-platform availability and ease of use. Modern web technologies allow to access monitoring interfaces through standard devices, without the need of specialised software. Web-based approaches, however, limit rendering performance, native OS integration, and real-time responsiveness, which can be critical for robotics supervision. Web-based and native desktop frameworks were evaluated during the development. A Python binding for Qt framework, PySide6, was decided to be used in the project to develop a native desktop operations center. The choice was driven by PySide6’s better rendering performance for real-time map visualisation, support for dockable panels and rich widget layouts, and the possibility to directly integrate with ZeroMQ transport and host YOLO inference inside the desktop application. The console runs YOLO in a crash-isolated subprocess, rather than in the UI thread, so a model crash, hang, or out-of-memory event cannot freeze or kill the operator console, a level of native integration and process control that a browser based dashboard cannot match.

Usually the integration of robotic systems and web-based dashboards are done using ROS compatible communication frameworks. The ROS web bridge technologies enable the transmission of real-time data between ROS nodes and external interfaces, allowing monitoring applications to receive live updates from the robot. Continuous low-latency data transmission is often required (e.g. to display time sensitive information such as the robot status, sensor readings and perception results) and communication protocols such as WebSockets are often used for this purpose. This project includes rosbridge as an optional debug-only fallback path, but it is not used in the production monitoring workflow. The primary data path is ZMQ/msgpack channels connected directly to the PySide6 dashboard.

Another important aspect of effective monitoring systems is map and environment visualisation. The literature points out the need of presenting SLAM outputs and spatial information in an intuitive way, so that operators can understand the robot’s surroundings and its own position in the environment. Proper visualisation of occupancy grid maps with perception and system state information can enhance the situational awareness and support safer and more efficient operation.

Overall, dashboard and monitoring frameworks are an important component in bridging the gap between autonomous robotic systems and human operators. These systems allow for real-time monitoring, interaction and visualisation, thus enabling reliable supervision and contributing significantly to the effectiveness of robotic platforms in complex and dynamic environments.

Before choosing and buying hardware components, we did a comprehensive literature review of the common used platforms and devices in mobile robotic systems, as depicted in Figure 2.1. The purpose of this review is to identify reliable and well-supported hardware solutions that meet the computational and operational requirements of the proposed system.

Processing platforms are the core of robotic systems and manage tasks of perception, communication and control. Single-board computers are often used alongside microcontrollers to provide a balance between computational power and real-time performance.

A review of the Raspberry Pi was made as a primary onboard computing platform due to its popularity in robotics. We chose the Raspberry Pi 4, with the 8 GB version in particular, given its processing capabilities and the amount of memory required to run ROS based applications such as SLAM and high-level system coordination. The Raspberry Pi 3B+ was also seen as a suitable secondary or supporting role but less powerful. The Raspberry Pi is a great platform for adding sensors and peripheral devices, with a strong community, good documentation, and general purpose input/output (GPIO) pins.

Arduino microcontrollers are also widely used for low-level, real-time control tasks, in addition to single-board computers. The Arduino Mega was reviewed for the number of input/output pins, with which it is possible to interface with several sensors and motors at the same time. Arduino platforms are particularly suited to time critical operations such as motor control and enjoy a wealth of well documented libraries that simplify development and integration.

Mobile robotic systems require a range of sensors to support perception, navigation and obstacle avoidance. The literature review focused on sensors that are commonly used and compatible with ROS-based architectures.

Two-dimensional LiDAR sensors are often used for SLAM and environment mapping. In the review, factors such as sensing range, measurement accuracy, scan frequency and ROS compatibility were considered. These sensors can provide reliable spatial information needed for building occupancy grid maps and for supporting navigation tasks.

Inertial Measurement Units (IMUs) were investigated to provide motion and orientation data. Factors considered include number of sensing axes (e.g., 6-axis, 9-axis), measurement accuracy, and integration with other sensors. IMU data can be very helpful to improve the localisation performance when combined with odometry data.

Ultrasonic sensors were also considered for low cost short range obstacle detection. While ultrasonic sensors are not as detailed as LiDAR, they are good at detecting nearby objects and can be used to supplement other nearby sensors.

USB cameras were reviewed for the visual perception to be used for object and human detection tasks. The main evaluation was made on image resolution, frame rate, and compatibility with popular image processing and deep learning libraries. Cameras provide key visual information for high-level perception and interaction with the environment.

The drive system is an important part which has direct influence on robot stability and control. The literature review examined various configurations of motors and drivetrains typical of mobile robots.

Being distributed and modular in architecture, the system allows real-time control to stay locally on each robot, while perception and visualisation are performed on the operations center. This separation improves system reliability , simplifies debugging and allows scaling . This architecture allows the Alpha mapping robot to share occupancy grid maps and localisation coordinates with the Beta and Gamma robots through the state store of the operations center without requiring direct robot-to-robot communication.

The overall system architecture allows for a coherent integration of the hardware and software components, enables real-time operation and provides a solid basis for further improvements and real-world deployment in environments such as hospitals, industrial facilities and other safety-critical locations.

The design of the hardware and software for the autonomous robotic system was developed concurrently so that physical components and computational processes are tightly integrated. Design decisions were driven by actual operational needs, reliability of the system and the need to support autonomous navigation, perception and monitoring in real world environments such as hospitals and industrial facilities. The system architecture is modular, easy to integrate and scalable for future development phases.

The hardware design of the system is based on a modular mobile robotic platform. It provides the capability of autonomous navigation, environment mapping, visual perception and environmental monitoring. The overall design emphasises robustness, scalability and ease of maintenance such that in later development phases the system can be extended to a multi-robot setup  The mechanical structure and component arrangement of the platform is shown in Figure 3.3.

The robot platform is a four-wheeled differential-drive type mobile platform. This configuration is chosen to ensure mechanical robustness, controlled manoeuvrability and reliable operation in indoor environments such as hospitals, offices and industrial facilities. Four individual DC motors drive all four wheels for 4WD skid-steer differential steering and accurate motion control so as to achieve sufficient traction and manoeuvrability under dynamic loads. The robot has a physical size of about 40 cm × 30 cm × 25 cm and a weight of about 10 kg per robot. The dimensions were chosen for the robot to be able to navigate through narrow corridors and tight indoor spaces, while carrying all the required sensors and electronic components.

The software design of the autonomous robotic system is based on a layered and modular architecture implemented with ROS 2 as the core middleware. This design methodology allows clear separation of hardware interfacing, control logic, navigation, perception and user interaction. The software architecture is designed to support real-time operation, system scalability and ease of maintenance while accommodating the current single-robot implementation and planned multi-robot expansion. Figure 3.5 shows the overall software stack and the interaction between ROS 2 nodes.

The software system is organised in five functional layers; each layer is responsible for a specific part of the system functionality. This layered architecture increases the clarity of the system and allows to develop, test and modify individual components independently.

This layer communicates directly with the physical hardware of the robot, such as motors and sensors. It conceals hardware specific details and provides standardised interfaces to higher level software components. This layer abstracts the hardware and isolates hardware dependencies so that hardware changes do not significantly affect the rest of the software system.

The control unit used is Arduino-based and is used for low-level control and time-critical tasks. This layer takes care of real-time motor control, reading wheel encoders, IMU data and basic odometry computation. This offloads computational load from the main processing platform, ensuring deterministic timing and responsive motor behaviour.
